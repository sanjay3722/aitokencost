# aitokencost.dev

A single-page tool: paste a prompt, see what one request costs per month across
OpenAI, Anthropic, and Google models. The product *is* the accuracy of the
numbers — see `VERIFY.md`.

## Stack

- **Next.js 16.3.4**, App Router, Turbopack. React 19. TypeScript `strict`.
- `src/` dir, import alias `@/*` → `src/*`.
- **Plain CSS**, one file: `src/app/globals.css`. No Tailwind, no CSS-in-JS.
- `js-tiktoken` for local OpenAI token counts.
- No test runner installed yet. No database. No auth.

> **Read the bundled docs, not your memory.** This Next.js is newer than your

## Project map

| Path | What it is |
| --- | --- |
| `src/lib/pricing.ts` | The model table. USD per 1M tokens, per-model `verifiedOn`. Editing this is the product. |
| `src/lib/calc.ts` | Token counting (memoised tiktoken + heuristic fallback), cost math, shared `compare()`, formatters. Pure, no React, no I/O. |
| `src/components/Calculator.tsx` | The one Client Component (`"use client"`). Holds all interactive state. |
| `src/components/ResultsTable.tsx` | Presentational Server Component. No state. Shared by both input modes. |
| `src/app/page.tsx`, `layout.tsx` | Server Components. Shell + Metadata API. |
| `src/app/globals.css` | The entire stylesheet. Light/dark via `prefers-color-scheme`. |

## Rules for this repo

1. **Server Component by default.** Add `"use client"` only for state, effects,
   or browser APIs — and push it as far down the tree as possible. Today only
   `Calculator.tsx` is a client component; keep it that way unless there's a
   real reason.
2. **`src/lib/*` stays pure.** No React imports, no `fetch`, no `process.env`
   reads at module scope. It must be unit-testable in isolation and safe to
   import from both server and client.
3. **Secrets are server-only.** API keys (for the future `/api/count` route)
   are read from `process.env` inside a route handler or server action, never
   in a component that a client bundle can reach.
4. **Prices carry a date.** Any change to a number in `pricing.ts` updates that
   model's `verifiedOn`. Never edit a price without checking the provider page.
5. **One stylesheet.** New styles go in `globals.css` with the existing token
   vocabulary (`--bg`, `--surface`, `--text-dim`, …). No inline `style=` beyond
   dynamic values, no new CSS files.
6. **Async dynamic APIs.** `params`, `searchParams`, `cookies()`, `headers()`
   are Promises in this version — always `await` them.
7. **`next/link` and `next/image`** for internal navigation and raster images.
   Provide `width`/`height` or `fill`.

## Workflow

```bash
npm run dev      # http://localhost:3000
npm run build    # production build + typecheck — must pass before commit
npm run lint     # eslint (next/core-web-vitals)
```

There is no test command yet. If you add logic to `src/lib/`, propose adding
`vitest` and a `*.test.ts` beside it rather than leaving it uncovered.
